# Community profiles

The desktop application includes a curated library of ready-to-use profiles. A profile must not contain personal data, private URLs, credentials, or machine-specific application paths.

To suggest a profile, open an issue or pull request with:

- the target model (`HCD-BASE`, `HCD-PLUS`, or `HCD-PRO`);
- a short name and description;
- the proposed short-press and long-press actions;
- the author name you want displayed.

Profiles are reviewed before being added to the catalog bundled with a future application update.
