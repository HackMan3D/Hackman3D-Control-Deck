# Privacy information

HackMan3D Control Deck uses a minimal first-party audience counter to understand
whether the project is actually being used and to guide its development.

## Data sent

When audience measurement is enabled, the desktop application sends:

- a random installation identifier generated by the application;
- a random temporary identifier for the current running session;
- start, heartbeat and clean-stop events;
- an aggregate count of actions executed.

The identifier is not calculated from the computer and contains no name, email,
account, serial number, MAC address or other hardware identifier. The server
stores only its SHA-256 hash. It cannot reliably identify a person: two computers
count as two installations, while multiple users of one installation count once.

Profiles, configured actions, application names, shortcuts, website addresses,
icons and documents are never sent.

## Purpose and access

The data is used only to produce private aggregate project statistics: active
instances, launches, action totals, new installations, installations seen over
30 days and total unique installations. It is not used for advertising, sold,
shared with other projects or combined with external data. Only HackMan3D can
access the private statistics endpoint.

## Control

Audience measurement is enabled by default and does not interrupt startup with a
consent dialog. It can be disabled at any time in the desktop application's
settings. Disabling it stops future events; the application continues to work
normally.

Because the server never receives an identity or account, it cannot associate a
stored hash with a named person. Removing the application's local settings also
removes its random identifier; a later launch will then be counted as a new
installation.
