# HackMan3D Control Deck community launch kit

## Short post

Build your own programmable desktop control deck. HackMan3D Control Deck is a
free, open-source project with integrated firmware installation and desktop
software for Windows, macOS and Linux. Assign shortcuts, system controls,
applications and long-press actions without using the Arduino IDE.

Download, build and documentation:
https://github.com/HackMan3D/Hackman3D-Control-Deck

If the project is useful to you, sharing your build or supporting continued
development helps fund the HCD Plus and HCD Pro prototypes:
https://ko-fi.com/hackman3d

One-time PayPal contribution:
https://paypal.me/Hackman3D

## Video caption

From printed parts to a working programmable control deck — firmware flashing

macOS and Linux. Build files, wiring guide, firmware and software are all on
GitHub.

## Suggested 30–45 second video

1. Show the finished HCD and press several configured keys.
2. Show the printed parts and electronics briefly.
3. Connect USB and show the integrated firmware installation.
4. Assign an application or shortcut in the desktop app.
5. Show the action working.
6. End with the GitHub download link and a discreet support link.

Lead with what the HCD does. Mention support only after demonstrating the
value of the project.
