# HackMan3D Control Deck 1.4.8

This release provides ready-to-install applications for macOS and Windows. The
HCD-BASE firmware and flashing tools are included, so Arduino IDE is not needed.

## Quick start

1. Install the application for your computer.
2. Connect the HCD-BASE by USB.
3. Open **Firmware**, select **HCD-BASE**, then install the included firmware.
4. Configure the nine keys and leave the application running in the background.

## Community support and roadmap

HackMan3D Control Deck is designed, developed and shared free of charge.
Community support helps fund prototypes, components, testing and continued
development.

The application displays a single roadmap gauge from 0 to 100%. HCD Plus is
shown as the intermediate milestone and HCD Pro as the final milestone. The
gauge updates as support is received, but only the resulting percentage is
published. Donation totals and financial targets are never displayed or
included in the application, release feed or public project files. The
application does not process payments; its support button only opens the
external HackMan3D PayPal page.

## HCD Plus and HCD Pro

Both future models appear in the firmware selector with an **in development**
label. They are previews only and cannot be installed from this public release.
Their installation will be enabled when the hardware and assembly guides are
ready for users.

HCD Pro is planned without additional physical buttons. Its display will offer
either 28 programmable touch buttons with one slider, or 24 programmable touch
buttons with two sliders.
