# HackMan3D Control Deck 1.4.9

This update improves the Windows action editor while preserving all macOS
features.

## Windows improvements

- Installed applications from the Windows Start menu now appear in the
  application selector, with their icons.
- Windows application icons are enlarged and normalised for clearer display in
  the desktop preview and on HCD Pro.
- System commands are read directly from the selected preset when actions are
  saved. This fixes commands such as increasing brightness or shutting down the
  computer not being retained reliably.
- Shortcut and system-command lists are filtered according to the current
  operating system.
- HCD Pro discovery retains both UDP and `hcd-pro.local` network detection.

## HCD family

HCD Plus and HCD Pro remain marked **in development** in the firmware manager.
Their firmware is selectable for HackMan3D prototype testing. Regular users
should build HCD-BASE until public assembly guides for the future models are
available.

HCD Pro has no additional physical buttons. It offers either 28 programmable
touch buttons with one slider, or 24 programmable touch buttons with two
sliders.

## Community roadmap

HackMan3D Control Deck is designed, developed and shared free of charge. The
community gauge is published only as a percentage. Donation totals and targets
are not displayed or included in the application or public release feed.
