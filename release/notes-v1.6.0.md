# HackMan3D Control Deck 1.6.0

This release introduces the optional HCD Supporter membership while keeping the
Control Deck fully functional for everyone.

## New

- Ko-fi HCD Supporter activation directly from the desktop application.
- Automatic membership renewal recognition after the first activation.
- Supporter status and validity date displayed in the application.
- Support reminders and the community funding banner are hidden while the
  membership is active.
- Ko-fi remains available for tips and membership; PayPal remains available for
  one-time contributions.

## Privacy and security

- The service stores no payer name, contribution amount, Control Deck profile,
  configured action or hardware identifier.
- Ko-fi email addresses and transaction IDs are stored only as keyed hashes.
- The desktop application receives a random revocable access token.
- One-time tips and PayPal contributions do not unlock the monthly membership.
