# HackMan3D Control Deck 1.6.2

This release uses the same **1.6.2** version number on macOS, Windows and Linux.

## Improvements

- adds a large 3 × 3 preview of the HCD-BASE long-press icons while keeping
  the main deck render focused on short-press actions;
- displays both short-press and long-press assignments on one screen;
- limits shortcut-conflict warnings to the controls available on the currently
  connected HCD model;
- prevents HCD Plus or HCD Pro assignments from creating irrelevant warnings
  while an HCD-BASE is connected.
